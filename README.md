## 🔬 Research & Focus Areas

The website showcases the centre's primary research verticals in applied geodesy:
* **Imaging Geodesy:** Utilizing InSAR and remote sensing for structural deformation monitoring.
* **Hydro-Geodesy:** Focus on Satellite Gravimetry (GRACE/GRACE-FO missions) and reservoir monitoring.
* **GNSS Meteorology & Reflectometry (GNSS-IR):** Retrieving geophysical variables using high-precision signals.
* **Precise Positioning:** Managing the infrastructure for **CORS (Continuously Operating Reference Stations)**.

---

## 🛠 Technical Stack

The project is built using a clean, lightweight frontend architecture to ensure fast loading times and accessibility:

* **HTML5:** Structured semantic markup for research data.
* **CSS3:** Custom styling (found in `style1.css`) providing 50% of the repository's logic.
* **JavaScript:** Interactive components for navigation and gallery features.
* **Deployment:** Optimized for **Vercel** integration.
